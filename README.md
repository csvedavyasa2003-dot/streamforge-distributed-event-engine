# StreamForge - Distributed Event Processing Engine

## Overview

StreamForge is a distributed real-time event processing system developed as part of the Axlero Solutions Internship.

The project demonstrates how large volumes of streaming events can be processed using Apache Kafka, Python, FastAPI, and React while monitoring the system using Prometheus and Grafana.

---

## Project Objectives

- Process real-time streaming events
- Distribute workload across multiple workers
- Build scalable backend services
- Visualize processed data through dashboards
- Monitor system performance
